# Archive

Docs that no longer describe how StageSight 3D works. They're kept for history, not maintained, and nothing outside this folder should link to them.

## When to archive a doc

Archive a doc when the feature, workflow or decision it describes is gone or has been replaced. Don't archive a doc just because it has small errors — fix it where it is.

## How to archive a doc

1. Move it here with `git mv` so its history follows it.
2. Add this line under its title:

   ```markdown
   > **Archived YYYY-MM-DD.** Superseded by [new doc](../new-doc.md) / No longer applies because …
   ```

3. Remove links to it from the [docs index](../README.md) and the root README.
4. Add a row to the table below.
